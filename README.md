# AmyUsage · Amy 流量

一个简洁的 macOS 菜单栏流量查看工具。点击菜单栏图标，查看订阅已用流量、剩余流量与总额度，也可以手动刷新。

使用 Swift 和 AppKit 编写，无第三方依赖，不包含代理内核。

这是个人项目，与 Amy 或其他订阅服务商没有隶属或合作关系。

## 功能

- 菜单栏弹窗显示已用、剩余、总额度和上次成功更新时间。
- 手动刷新，或每 15、30、60 分钟自动刷新；默认 30 分钟。
- 可直接在菜单栏显示剩余流量。
- 如果订阅提供到期时间，会显示订阅到期日期。
- 更新失败时保留本次运行中的上一次成功数据。
- 订阅链接保存在本机钥匙串；输入框以圆点隐藏内容。
- 支持 ⌘V 粘贴，另有“粘贴链接”按钮。
- 网站账户查询：登录后自动查找套餐、读取用量并完成绑定；多个套餐时沿用历史选择或选择一次。

## 从源码构建

需要 macOS 13 或更新版本，以及 Apple 的 Xcode Command Line Tools（提供 Swift 编译器）。构建脚本会生成当前 Mac 架构的应用。已在 Apple 芯片 Mac 上使用，Intel Mac 尚未实测。

在项目目录执行：

```sh
zsh build.sh
```

构建脚本会编译、执行本机签名，并运行 15 项流量计算与链接校验检查。生成的应用位于：

```text
dist/AmyUsage-1.3.0/Amy流量.app
```

将应用拖入“应用程序”，双击打开。本仓库只提供源码，不包含预编译应用；本机构建签名不等于 Apple 公证。

## 使用

### 网站账户查询（1.3.0 支持登录后自动查询）

当订阅获取受到开关或有效期限制，而官网仍可查看套餐流量时，可以使用此模式。

1. 在小工具中点击“网页登录/套餐”。
2. 在程序内的 Amy 官方网页自行登录。只有一个套餐时，程序会自动进入并读取流量；有多个套餐时，优先沿用之前选择，否则需要选择一个。
3. 读取成功后自动保存并关闭登录窗口，无需点击确认按钮。小工具切换为网站查询，继续支持手动和定时刷新。
4. 登录会话过期时，重新打开“网页登录/套餐”登录，程序会再次自动处理后续步骤。

WebKit 的登录会话保存在本机，与 Safari 独立。可在设置中点击“清除网页登录”删除本程序的网页数据。网站模式需要加载网页，资源占用会高于订阅模式；1.2.1 在运行期间保留同一个网页视图与会话，以减少重复创建造成的状态变化，内存占用可能增加，实际进程占用尚未测量。当前通过网页可见文本识别用量，页面结构或语言变更、验证码、网站限制均可能导致查询失败。网站显示的流量已经经过四舍五入，总额度由已用和剩余相加得到。

这不是服务商的独立官方 API。维护者已在 Apple 芯片 Mac 上试用确认 1.3.0 可用；不同账号、网站变更及长期运行情况仍可能有差异，首次使用请与官网数据核对。

### 订阅链接查询

1. 从自己的订阅服务商处复制 HTTPS 格式的 **Clash 订阅链接**，不是订阅管理页面的网址。
2. 打开应用，在设置中点击“粘贴链接”或使用 ⌘V，点击“保存设置”。
3. 点击顶部菜单栏的饼图图标，查看用量；点击“立即刷新”重新查询。

更多说明见 [使用说明](使用说明.md)。程序不会设置开机启动。

## 隐私与权限

- 订阅模式不需要网站密码；网站模式由用户在官方网页自行登录，不读取 Safari 登录信息。
- 不申请管理员、辅助功能、录屏、全盘访问或 Safari 权限。
- 不包含广告、遥测或第三方订阅转换服务。
- 订阅链接只保存到本机钥匙串，不写入源码或普通配置文件。刷新和显示偏好保存在本机应用偏好中。
- “粘贴链接”按钮只在用户点击时读取剪贴板。
- 使用 HTTPS 证书验证。订阅模式拒绝跨主机重定向；网站模式只允许顶层页面在 Amy 官方域名内导航。
- 订阅模式仅查询用户填写的订阅服务器；每次刷新仅发起一次 GET 请求，在收到响应头后取消正文下载。网站模式加载 Amy 官网及网页所需资源。
- 订阅请求不使用系统配置的 HTTP 代理；网站模式按 WebKit 的网络行为加载官网。VPN 是否接管底层连接仍由系统/VPN 决定。

**不要在 Issue、截图、日志、代码或提交记录中公开自己的订阅链接、令牌、账号资料或节点配置。** 订阅链接具有访问订阅的能力。

## 兼容性与限制

订阅模式的数据来源为订阅响应头 `subscription-userinfo` 中的 `upload`、`download`、`total` 和可选的 `expire`。不提供此响应头的服务商不支持订阅模式。网站账户模式目前只支持 Amy 的中文套餐详情页面。其他服务商兼容性尚未逐一验证。

- 用量更新速度取决于服务商，手动刷新无法消除服务商自身的统计延迟。
- GB 按 1024³ 字节显示，可能与服务商采用的显示单位不同。
- 总额度为零按不限量处理；月度重置时间不从到期时间推算。
- 退出后不保留流量缓存。
- 同一个订阅主机内的 HTTPS 重定向可以跟随，跨主机重定向会拒绝。
- 轻量是项目目标，内存占用尚未系统测量。
